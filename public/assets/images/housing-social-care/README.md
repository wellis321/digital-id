# Housing & Social Care Images

This directory contains images for the Housing & Social Care use cases page.

## Required Images

Place the following images in this directory:

1. **hero.jpg** - Main hero image for the page (4:3 aspect ratio, showing Digital ID in use)
2. **building-access.jpg** - Staff member scanning QR code at building entrance/turnstile
2. **care-home-access.jpg** - Staff member being verified at a care home entrance
3. **banking.jpg** - Staff member showing Digital ID at a bank counter
4. **housing-provider.jpg** - Staff member at a housing provider office
5. **hospital.jpg** - Staff member at a hospital with a client
6. **training.jpg** - Staff checking in for a training session using QR code
7. **rewards.jpg** - Staff member registering for employee discount/reward

## Image Guidelines

- Recommended size: 1200x900px (4:3 aspect ratio)
- Format: JPG or PNG
- Quality: High resolution for web use
- Style: Professional, clear, showing the Digital ID app in use

## Image Placeholders

If images are not available, the page will display placeholder text. Add images with the exact filenames listed above to replace the placeholders.
